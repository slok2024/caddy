Caddy 是一个用 Go 语言编写的、现代化的、开源的 Web 服务器和反向代理工具。它以“自动 HTTPS”（Automatic HTTPS）和极其简洁的配置著称，被广泛用于替代传统的 Nginx、Apache 或作为云原生环境中的微服务网关。

核心特性
默认自动 HTTPS：Caddy 在启动时会利用 Let's Encrypt 或 ZeroSSL 自动申请、配置和续期 TLS/SSL 证书，全程无需人工干预。它还会自动重定向 HTTP 到 HTTPS。

直观且强大的配置语法（Caddyfile）：摒弃了复杂的 Nginx 嵌套花括号语法，Caddyfile 采用人类可读的声明式语法，通常只需几行即可搭建一个功能完备的服务。同时它也支持完整的 JSON API 动态配置。

原生支持现代协议：开箱即用支持 HTTP/1.1、HTTP/2 以及现代的 HTTP/3 (QUIC)，无需额外复杂的编译或调整。

模块化与可扩展性：Caddy 基于 Go 语言编写，采用模块化架构。通过官方提供的构建工具 xcaddy，用户可以非常方便地将第三方插件（如 DNS 验证插件、特定认证模块等）编译进核心二进制文件中。

内存安全：得益于 Go 语言特性，Caddy 在高并发场景下具有极低的内存开销和极高的稳定性，且不存在传统的 C/C++ 内存溢出风险。

常见应用场景
高效的反向代理与负载均衡：常用于将外部请求安全地转发到内网或 Docker 容器中的各个后端服务（如面板、博客、API 等）。

静态文件服务器：单行命令即可快速启动高性能的静态资源托管服务。

自托管（Self-Hosted）基础设施网关：在 HomeLab 或云服务器（如 VPS）上作为统一入口，结合动态 DNS 和自动 SSL 证书管理各种本地服务。

API 网关与微服务路由：利用其丰富的中间件和强大的重写/重定向规则进行流量调度。
